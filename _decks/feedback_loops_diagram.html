How confidence is earned: the feedback loops

Next iteration of the node / edge / atom picture. Same pieces, now showing the data flowing through the loops that turn a guessed confidence into an earned one.

Box = a step  ·  cylinder = a stored ledger  ·  arrow label = the data that moves  ·  an atom = one cited, timestamped fact with a confidence of { n, width, basis }

1. The core loop: emit, observe, deposit, re-earn

Two rules on this loop. Isolation: a single customer's private outcomes never enter the shared ledger; only public or explicitly-shared outcomes do. Honesty: confidence stays labeled asserted until enough outcomes exist to be trusted, then it becomes earned. It never shows an earned-looking number it has not earned.

Two ledgers because two different things can be right or wrong: whether the event happens, and whether, once it does, it actually moves the subject. Keeping them separate stops a mistake in one from hiding inside the other.

Every feedback loop in the system is the same move: do something with a stated confidence, watch what actually happens, record it, and let the next attempt be smarter. The earned-confidence loop does it for facts, the forward engine does it for predictions, and the autonomous engines do it for the product itself.
