One shared building code, many homes

The building code lives once, on its own node. Each home points to it with an edge. The code fact is shared by reference, never copied onto each home. Parcel-specific facts hang off the individual parcel.

Amend the code once on the code node, and every parcel's governed_by edge sees the new version. If the code were an atom on each home instead, the same change would mean rewriting it on every parcel. That is why shared facts live on a shared node, and only parcel-specific facts hang off the parcel.
