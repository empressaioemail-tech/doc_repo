Four things make this work. 1) The source tag rides inside the atom, so ICC's authorship travels with the code wherever it goes. 2) The gate meters every consumption and attributes it. 3) Lineage attribution: if an answer was reasoned from ICC's code (a derived atom), the usage still attributes back to ICC. 4) Settlement pays ICC its per-use share and gives an anchored, tamper-evident receipt it can audit independently.

Built vs designed (honesty): the metering and usage ledger are the mechanism; the automatic per-source payout is designed and partly built (settlement runs through a single wallet today, revenue share is contractually promised). The receipt anchoring reuses the same sealing step as the verifiable track record.

The pattern underneath all four

Every loop is the same move: do something, record what happened in a ledger, then act on the ledger. The calibration loop records outcomes and re-earns confidence. The forward engine records resolutions and effects. The autonomous engines record app signals and self-correct. Monetization records consumption and settles payment. One shape, four ledgers: confidence, resolution, effect, and usage.
