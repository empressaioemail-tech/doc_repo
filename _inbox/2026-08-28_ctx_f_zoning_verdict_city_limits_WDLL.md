# CTX card F: unincorporated is a finding about a boundary, never about a null

Date: 2026-08-28  Status: approved

Six counties serve the full facet shape in production and the walk grades presence, provenance, and content structure. It cannot see that one verdict on that shape is a wrong statement. Every conformant-baked parcel without a zoning stamp, in a county whose unincorporated territory is unzoned, is served as `not-applicable: unincorporated, no zoning authority`. The predicate reached that from a null `situsCity`, which the conformant assemble never mapped from the claim. A parcel in central Austin is told it has no zoning authority. The honest answer for that parcel is that its zoning stamp is missing, and the honest way to say `unincorporated` is a populated city-limits index with the point outside every polygon. That code exists and is uncalled.
