## Section D: `.ps1` stdin contract

All five `.ps1` gates read stdin as JSON: `$stdin = [Console]::In.ReadToEnd()` then `$stdin | ConvertFrom-Json`, failing open on blank or unparsable input.

- `branch-guard.ps1` and `dirty-tree-close-gate.ps1` read `tool_input.command` and `tool_input.working_directory`, falling back to top-level `cwd` (via `.claude/hooks/_git-repo-target.ps1:34-47`). Field read is **`tool_input.command`**; `tool_name` is read only by dirty-tree (`_git-repo-target.ps1:38-41`).
- `canon-gate.ps1` and `dispatch-template-gate.ps1` read **`tool_name`**, then for `Agent` **`tool_input.prompt`** (also array/`value` forms, `canon-gate.ps1:151-172`), for `Write` **`tool_input.file_path`** (or `path`) plus **`tool_input.contents`** (or `content`). Write is only inspected under `_dispatches/` (`canon-gate.ps1:198-204`; `dispatch-template-gate.ps1:104-107`); any other Write exits open.
- `canon-divergence-run.ps1` reads **`tool_name`** (must be `Read`) and **`tool_input.path`** (or `file_path`), refusing to act unless the path ends `_STATE.md`.
- Adapter confirmation: a raw Cursor payload `{"command":"git push origin main","hook_event_name":"beforeShellExecution","cwd":"","workspace_roots":["/p:/doc_repo"]}` through `node .cursor/hooks/run-gate.mjs powershell .claude/hooks/dirty-tree-close-gate.ps1` returned `{"permission":"deny",...}` and the same with `git status` returned `{"permission":"allow"}`, confirming `.cursor/hooks/normalize-payload.mjs` maps top-level `command` into `tool_input.command`.
