## The reframe (load-bearing)

The pickup list reads as a data-acquisition backlog. It is not. Traced to source, the map is not starved for sources. It is starved for two things: **render/wiring** (data already ingested that no map layer draws) and **derivation** (composite reasoning that returns fixtures instead of computing over inputs that already exist). Exactly one item on the entire list requires touching a source we do not already have, and that one is a commercial gate, not a technical one.

The sourcing plan therefore sorts every gap into four buckets by what actually unblocks it:

- **Bucket 1 — already-ingested federal data, needs a renderer.** No acquisition. The single largest bucket.
- **Bucket 2 — real data, blocked on the tile+CLIP cache (already designed, unbuilt) and on Cotality keys.** Affordability, not source. Now also a commercial gate.
- **Bucket 3 — composite derivations.** The only real engineering. All four inputs already live; none is a source problem.
- **Bucket 4 — not-a-source at all.** Renderer, dead-code, honesty-pill items mis-filed as data gaps.

Source-of-record for each item is named so a deferral is a pickup with a known feed, never a silent drop.

## Bucket 3 — Composite derivations (the only real engineering; commitment #1 blocker)

All four composites (`buildable-envelope`, `constraint-density`, `oz-deal-crossfilter`, `motivated-seller`) live in `brokerageGisCompositeLayers.ts` and today return `buildCompositeLayerFixture` — entirely hardcoded, geometry derived from the bbox alone, honesty `degraded: true` on every response. The function takes only `(layer, bbox)`; **no data source is wired in at all.** Promoting each to a real derivation is the wedge-surface (commitment #1) work. Critically, none is blocked on a source we lack — every input is already live in the spine.

Scoped per the operator's "scope all four now" call:

### buildable-envelope
- Inputs (all live): parcel geometry (county-GIS / TxGIO / Cotality Spatial Tile), zoning attributes (`fetchSiteLocationZoning` land-use/zoning codes; the ZONING_ENRICH path), and dimensional standards from the code corpus (setback / FAR / height / lot-coverage atoms in the 34-juris corpus).
- Method: intersect parcel polygon minus setback offsets, cap by FAR/height/coverage from the zoning atoms, emit the buildable ring + `buildableAreaPct` as a derived geometry.
- Source-of-record: county-GIS parcels + code-corpus dimensional atoms. No new source.
- Confidence/provenance shape: earned from (a) whether the zoning atom for this jurisdiction exists and its edition freshness, (b) parcel geometry precision. Falls back to neutral no-coverage where the jurisdiction has no dimensional atoms — never a fixture 78%.

### constraint-density
- Inputs (all live): FEMA NFHL flood, SSURGO soils (drainage/HSG/shrink-swell), hydrology drainage zones (pysheds), Edwards aquifer, MUD/PID, plus zoning overlays.
- Method: stack the already-ingested constraint layers over the parcel/bbox, weight by severity, emit a density surface. This is a composition over live layers, not a source pull.
- Source-of-record: the Bucket 1 federal layers + hydrology + FEMA (all live). No new source.
- Confidence/provenance: per-cell provenance is the union of contributing layer provenances; coverage-honest where a contributing layer has no coverage.

### oz-deal-crossfilter
- Inputs (live): Opportunity Zone designation is **already a live layer** (bundled federal CDFI tract GeoJSON, `resolveOzTractSlot`, point-in-polygon, zero upstream call — confirmed in the 2026-06-19 map-layer audit). The "crossfilter" combines OZ membership with deal signals (radar tier, propensity).
- Method: intersect OZ tract membership with the deal-scoring signals; emit tracts that pass both. The OZ half needs no acquisition; the deal-signal half depends on the Bucket-2 rent/propensity decision (Cotality-derived signals are gated by the eval clause — so the shippable v1 uses OZ membership + public-record deal signals only, not Cotality propensity).
- Source-of-record: bundled CDFI OZ GeoJSON (live) + whatever deal signals survive the commitment-#1 / eval-clause filter.
- Vintage note: whether the bundled OZ GeoJSON is current or should be refreshed from the free CDFI Fund designation shapefile (the only genuinely new source anywhere on this list) is an OPERATOR ruling — see R2. v1 crossfilter can proceed on the bundled vintage regardless; R2 only decides a refresh.

### motivated-seller
- Inputs: the real signal is CAD-derived — absentee ownership, tax delinquency, tenure/hold length, transfer recency, equity position. **All of these are in the `cad_property` store already** (owner/tax/absentee slots live since 2026-07-13, 1.07M+ rows). The fixture hardcodes `motivatedSellerHeat: 0.74` / `absenteeOwner: 1` / `taxDelinquency: 0.55`.
- Method: a scoring model over live CAD fields, not a data pull. Because it produces a wedge-surface score, it is the composite most exposed to commitment #1 (and to commitment #2 — the score must carry provenance + verification state, not a bare asserted number). The specific scoring/weighting + provenance shape is an OPERATOR ruling — see R3. The Cotality propensity input stays OUT under the eval clause regardless; the model runs on public-record CAD signal only.
- Source-of-record: `cad_property` store (free CAD bulk rolls). No new source.

Sequencing (this track's build order, independent of the rulings): oz-deal-crossfilter and buildable-envelope first (cleanest inputs, no ruling blocks the core derivation), constraint-density second (composition over Bucket-1 layers), motivated-seller last (gated on R3). Each ships only when its confidence + provenance shape is earned; until then it stays out of the Brief, per the existing fixture-degraded guard. No composite reaches a public surface as a fixture — that is the commitment #1 line.

## Discipline this track runs under (confirmed)

One agent per independent workstream, parallel where files are disjoint, sequenced where they share a file (the composites). Adversarial review of every subagent deliverable traced to live source — verification never delegated to the executor; no premortem scorecards. Fresh tmp clone per build agent, push-after-first-commit so nothing strands when the shared `P:\` clones are branch-switched, exit-bounded verification, no dev/watch servers. Merge only on green CI — local runs are not a substitute. No fixture reaches any public surface; fixture composites stay out until the derivation is real (commitment #1). Every composite output carries reasoning + source + confidence + timestamp; confidence earned or honestly asserted-with-provenance, never bare.
