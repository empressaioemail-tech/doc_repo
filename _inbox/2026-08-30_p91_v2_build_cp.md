Answer: the operator ruled that every opened parcel lands in Claude's context; a neighbor opened from a shared line is an opened parcel. Same path as the board's Open, same sentences.

Claim: a zoning tint by district family is a category, not a number (I2). Attack: five families read as a ranking. Answer: the families are nominal (residential, commercial, mixed, public) and use existing tokens with no ordinal scale; the district text is what carries meaning, the tint only groups.

Claim: the scale bar is a unit reference, not a parcel measurement. Attack: it is a number the panel derived. Answer: it is chosen from a fixed list (10, 25, 50, 100, 200 ft) and drawn at the ring's pixel scale; it asserts nothing about the parcel; labelled as a reference. If the operator reads it as a claim, it comes out.

Claim: B2 (duplicate declared, not refused) needs no migration. Attack: a screen holding two queries for one parcel loses the second query text. Answer: the second query is declared in `degraded.duplicates` with the kept query named; the screen holds parcel references by definition, so the row is the same row. What is lost is a durable record of the second spelling; named as a leave-behind if the operator wants it persisted (that is a column).

Claim: `unread` as an explicit section disposition is a wire change the MCP must respect. Attack: the MCP normalizer derives disposition and would rewrite it to `absent`, so the drainage section would lie in the other direction. Answer: S10 changes the normalizer to keep an explicit disposition and to fail closed only on a `present` claim with no data; S9 emits the section; the served suite paints `unread` as the gold dot. The two lanes build to the same shape written in their briefs.

Claim: node-depth arrays capped at 25 lose nothing a user needs. Attack: a user with forty parcels wants forty briefs. Answer: forty briefs is about 188,000 characters, which the host turns into a file pointer the panel cannot read; twenty-five is the largest batch that arrives.
