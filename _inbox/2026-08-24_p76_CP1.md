## How would a zero-row table currently be reported?

**Unincorporated.** Not unmeasured. Does not crash.

`resolveCityContainmentAtPoint` walks the in-memory index and, on no hit, always returns `{ status: "unincorporated", basis: "no incorporated-place polygon contains the query point (tx_city_boundary statewide index; …)" }`. An empty array is a no-hit. `resolveCityContainment` also returns unincorporated when the parcel yields no representative point.

A zero-row `tx_city_boundary` therefore cannot be distinguished from a populated index whose polygons miss the point. That is the defect this card fixes before any serve wire.
