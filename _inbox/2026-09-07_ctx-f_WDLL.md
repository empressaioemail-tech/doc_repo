## What done looks like, in this lane's own words

1. **The readiness gate exists and is armed.** A per-(county, rail) check runs inside
   `runBastropPublish`, before the first bake invocation, for both staging and production
   targets. It refuses the publish when a required rail has no `parcel_gate_verdict` row
   (never evaluated — neither populated nor a declared absence) or when its verdict is
   `refuse` (>=1 unaccounted cell). `pass` and `excluded` both clear it. Proven by violation:
   a unit test seeds one rail as `refuse` and confirms the publish throws before any bake
   function is called; a second seeds a rail as simply absent and confirms the same.

2. **Staging can run from its own template.** `factory-staging-reset`'s Cloud Run job template
   in `cloudbuild.publish.yaml` carries live, re-derived (not pasted-from-11-days-ago)
   `NEONDB_NEON_PROJECT_ID` / `NEONDB_NEON_PARENT_BRANCH_ID` / `HAUSKA_MCP_NEON_PROJECT_ID` /
   `HAUSKA_MCP_NEON_PARENT_BRANCH_ID`. No execution-time `--update-env-vars` override is needed
   for a plain `gcloud run jobs execute factory-staging-reset --wait` to succeed.

3. **The secret-rotation loop has a code path.** After `staging-reset` creates fresh Neon
   branches and writes `staging_targets`, something in that same run updates
   `STAGING_NEONDB_URL` / `STAGING_HAUSKA_MCP_URL` in Secret Manager to point at the new
   branches — no hand step. Pooler hosts are refused, matching `connect.mjs`'s existing rule.

4. **The sibling check has a recency bound.** `requireStagingSibling` refuses a staging sibling
   older than a named, documented bound with its own refusal code — a 9-day-old sibling can no
   longer silently satisfy Rule 6.

5. **The pin question is answered with evidence, not assumed.** The transitive import closure
   of the four bundled LDT CLIs is diffed between the pinned SHA and current LDT main. If clean,
   `_LDT_SHA` and `_CONTRACT_VERSION` are bumped with the diff as evidence attached. If not
   clean, the pin stays and the finding is reported instead of bumped.

6. **Tier-2 conformant cannot run in this bake.** The stub that would null ~18,100 real flood
   facets and stamp Null Island coordinates is not invoked by default; the capability is not
   deleted (retirement is an operator ruling), and the retirement question is flagged, not
   decided.

7. **Two facts are recorded, not fixed:** no lease/advisory-lock serializes concurrent bakes;
   the bake's own run record carries counts, never a parcel-id manifest, and a refusal leaves
   no name at all. Recorded in the close; no code built for either unless it falls out of the
   gate work above for free.
