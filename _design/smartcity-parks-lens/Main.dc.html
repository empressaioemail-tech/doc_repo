Parks is named, and it is not built.

Every other department page on this roster exists and may be waiting for a source. This one is not. Nothing is connected, nothing is pending, and no grant would fill it, because there is no region here to fill. What is in the way is a source that does not exist: the build sheet records Parks facilities as gates: none yet, and the product will not register a region against a vendor it cannot name.

Basis, verbatim from the composer: parks-facilities is not a registered domain, so this surface is not built. Status: not-registered, the same on every pack. A state that does not vary by city is a statement about the PRODUCT.
Why it cannot simply be added three refusals, in the product
assertDomainShaperefuses a region whose gate is not one of the ten catalogued vendor kindsgated by parks, which is not a catalogued adapter kind
assertCityPackShaperefuses a city pack that names an uncatalogued kindfixtureGrants names parks, which is not a catalogued adapter kind
composeDomainrefuses a record whose vendor id does not match the region’s gatereturned a X record but is gated by Y
Basis: the three messages are the product’s own, from src/fixture-seam.mjs, src/city-pack.mjs and src/fixture-seam.mjs composeDomain. src/department-domains.test.mjs pins all three against a probe domain named parks-facilities, so the finding is inherited measured rather than re-derived.
What would change this one thing, and it is not engineering
1A parks or facilities system is identified and catalogued as an adapter kind
2A domain is written under that kind and appended to DOMAIN_REGISTRY
3Only then does this page become a built region that can be empty with a basis
The ten catalogued kinds are mygov, samsara, opengov, esri, municode, firstdue, verkada, spireon, goto, powerbi. None is a parks system, and an eleventh is a contract rather than a sprint item.
What Parks is not three near misses
A map layerproperty-map-catalog.mjs catalogues a parks polygon layer. A geometry layer is not a department register, and whether it returns features anywhere is UNESTABLISHED here.
A rolestaff-identity.mjs carries parks in DEPARTMENT_ROLES. A role that can be issued is not a surface that can be opened, and lens access is not enforced yet.
A register rowshell-homes.mjs routes Departments including Parks and Courts here, disposition Not built. That row is the pointer, not a source.
Each is real, none is this lens. Filling this page with one would claim coverage it does not have.
