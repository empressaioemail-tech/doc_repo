| File | Surface | What it shows |
|---|---|---|
| `mox_01_command.html` | Command center | Portfolio read across 40 communities + 3 arms; "needs your call" action inbox; "what the core learned this week"; Ask Mox rail. Persona: Miguel Arce (CEO). |

| `mox_03_manage.html` | Manage app | Monthly close + variance with auto-drafted commentary, pre-coded invoices, exception review, churn signal. Persona: Andrea (property accounting). |
| `mox_04_invest.html` | Invest app | Underwrite vs operating reality (portfolio actuals beat broker pro forma), owned-asset actuals vs underwrite, parcel intelligence, predictive twin, pipeline. Persona: Sean (CFO/acquisitions). |
| `mox_05_build.html` | BLDR app | Multi-jurisdiction code intelligence + pre-submission plan review with cited findings (accept/edit/reject), scope + subcontractor history. Persona: Joe Goss (construction). |
| `mox_06_flywheel_diagrams.html` | Flywheel diagrams | Three views: the mechanic (surfaces consume + contribute), private vs shared (gate routes deposits), why it compounds (Manage/Invest/BLDR feed each other on Mox's own outcomes). |
