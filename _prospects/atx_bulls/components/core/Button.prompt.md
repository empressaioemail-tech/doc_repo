# Button
The site’s one loud action — orange, chamfered, arrow-tailed.

```jsx
<Button size="lg" glow>Get in the arena</Button>
```

Sizes map to real site controls: sm 42 (nav, inline), md 56 (default), lg 64 (tryouts), xl 68 (merch). `variant="bone"`/`"ink"` exist only for the orange invert sections. Labels are 2–4 shouted words. Do not add a radius or a second chamfer.
