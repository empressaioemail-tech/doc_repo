# Stamp
Tilted circular badge on hero photography — tryouts, uniform, merch.

```jsx
<Stamp lines={["ARE","YOU","READY?"]} />
```

Copy examples in market: "ARE YOU READY?", "OFFICIAL 2027 UNIFORM", "OFFICIAL DROP 001". Keep the 8° tilt and the frosted dark fill; it should read like a printed rubber stamp on the photo.
