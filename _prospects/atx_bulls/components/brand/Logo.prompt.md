# Logo
Official bull-head mark and ATX BULLS lockup.

```jsx
<Logo variant="lockup" height={220} dropShadow />
```

Loads the live transparent PNG and falls back to the local copy in `assets/`. Minimum mark height 32px. On an orange field use the lockup with ink outline shadows so it punches off the background. The AF1 mark is the league’s, keeps its own navy/red, and is never recoloured.
