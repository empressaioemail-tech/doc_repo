# JoinInvert
Bottom-of-page VIP capture, and the template for any conversion moment.

```jsx
<JoinInvert sub="Be first to know when tickets drop!" socials={["instagram","twitter","youtube"]} onSubmit={save} />
```

Use the orange invert once per page, at the point of conversion. Placeholder is literally "YOU@EMAIL.COM". Submit is an ink block with bone type, not a chamfered orange button.
