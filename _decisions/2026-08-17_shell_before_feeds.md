# Decision

Stop putting data feeds onto Dashboards until the shell names a home for every G-18 / live-Bastrop staff function. Next card is shell completeness (G-73), not another adapter grant.

## Context

Operator rejected treating the G-71 municode write as progress toward Bastrop. The first public feed used Bastrop's clerk host on `template-city`, which collapsed the demo into Bastrop content. Operator: work on the shell and get everything; review the inventory and make homes for everything before more feeds. The live city still has Emergency, Operations, Prophecy, PermitFlow, VFD, CIP, phones, cameras, department pages, and more that G-66 never named.

## Structural commitment check

- Sell reasoning, not data: a named empty home is honest; a Bastrop agenda on the demo is not.
- Tenant sovereignty: live Bastrop stays the island. Demo does not wear its clerk calendar as proof.
- Cost per jurisdiction: one shell, many packs. Homes are cheap. Feeds are not.
- No privileged data: no morning-brief, no work orders, no staff names on unauth Dashboards.

## Reasoning

G-18 already inventoried the live city. 30c already traced most jobs. The live shell only shows four lead lenses, four Not-built departments, Plan review, and Files. That is not "everything." A feed into a hole makes the hole look like a city. The Connections page plus the missing City / Parks / Records-search homes are how the product admits the rest of the roster without ingesting it.

## Reversal criteria

Reverse the feed pause only after G-73 is graded and the operator names the next source. Reverse "Connections is the long-tail home" only if a department must be a first-class lens this wave. Reverse "Demo may see the City group" only if the operator wants the 30c demo-visitor hide rule back.

## Dependencies

Depends on G-18 inventory and 30c IA. Unblocks G-73. Holds further grants after G-71. Does not start G-52. Does not fill G-24. Live Bastrop no-touch.

## Counterparties

Internal: operator, Lane B. Live city: Bastrop staff on `smartcityos.io`. Demo: `template-city` on Dashboards.
