## Decision

C7's graded-ground-truth title-method leg runs on the Winkler County package Herbert already delivered (Sec 25 Blk B-5: 322-page county-index runsheet plus the certified WI report for the same section). Winkler is the method baseline, not a change of target: Reeves County remains the O&G vertical's target county and first mint corpus. The Reeves graded slice follows when Nick sources a Reeves runsheet, and it becomes the first measured county-to-county variance point rather than the first baseline.

## Context

The 85b filing flagged the option; the operator resolved it 2026-07-07 evening: "we are doing Reeves county but Herbert had docs for Winkler to set as a baseline. that will be a base that we build off of and we will have to adjust over time. there will be nuances so we need to account for that somehow."

## What was decided

1. Run C7 on Winkler now. The package is self-contained, already in-repo, and cost $0; Herbert grades method (run-sheet structure and chain construction), consistent with the 85a re-scope where he grades method rather than facts.
2. Reeves stays the target. Nothing about the vertical's sequencing changes: C6 (Reeves mint) and the twin stay Reeves-first; Winkler atoms produced during grading are method exhaust, not a second corpus commitment.
3. County nuance is a first-class artifact. The method carries a per-county variance ledger: every assumption the Winkler baseline bakes in (index structure, instrument-type vocabulary, recording conventions, depth-severance patterns) gets recorded as an explicit ledger entry when the method meets a new county, with the divergence and the adjustment noted. The ledger is the "account for nuances somehow": it turns county-to-county drift into recorded, calibratable method deltas (commitment #2 applied to the title method) instead of silent breakage.
4. The Reeves runsheet, when sourced, is graded against the Winkler-calibrated method — its purpose upgrades from "first ground truth" to "first variance measurement."

## Reasoning

The baseline question and the target question are independent. Ground truth quality is about the grading package (certified WI report tied to the exact runsheet), which Winkler has and Reeves does not yet. Target selection is about market activity, which Reeves has (3,887 W-1s since 2022, 53% allocation/PSA). Waiting on a Reeves runsheet to start the method leg serialized two things that do not depend on each other.

## Reversal criteria

Revisit if the Winkler package proves structurally unrepresentative of Permian county-index practice (the variance ledger would show the baseline assumptions failing wholesale on the second and third county rather than adjusting incrementally), or if Herbert's method grading finds the WI report unusable as ground truth.

## Constraints carried forward

The DOTO PDF remains an internal grading exemplar only (EOG attorney work product; never redistributed, never cited in product output). The Winkler WI report is Herbert's professional work product: internal grading use, same handling.
