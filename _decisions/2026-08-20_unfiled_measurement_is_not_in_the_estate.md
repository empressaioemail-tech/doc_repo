## Decision

A measurement that exists only outside version control is not in the estate. It cannot enter a verified count, and discovering that it was never filed is the finding, not a prompt to reconstruct it from memory.

## Context

C12 was asked to verify 157 retrieval candidate rows S-25 through S-182. The table lived only in a Claude transcript. Commit e6de1eb named the range and filed W-30; it did not contain the table. Zero of 157 entered the verified 48. The operator named this as the third instance this week of the same shape, after S-21 and F-0.

## Structural commitment check

Instruments over narration. A transcript is not a store. Reconstructing an unfiled list and then verifying the reconstruction would launder the miss.

## Reasoning

The 157 could not be verified against a list that never entered the estate. Sampling the transcript original is archaeology, not canon. The next reader of doc_repo still cannot cite S-25 through S-182. Filing the absence is what keeps a later pass from treating a reconstructed enumeration as the original.

## Reversal criteria

Reverse for a given list only if that list is filed in a tracked path and cited by tracked canon, at which point it is in the estate and ordinary verification applies.

## Dependencies

C12 close. Does not reopen W-30 (A1) or the verified 48.

## Counterparties

Internal. Planner files. Operator named the pattern.
