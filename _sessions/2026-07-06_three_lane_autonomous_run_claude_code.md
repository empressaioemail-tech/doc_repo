## Process lessons (memorized where durable)

1. **Live probes after every deploy catch what tests cannot** — three defects today existed only at integration seams (proxy forwarding to upstream root; upstream SPA fallthrough; secrets referenced-not-created).
2. **Adversarial review must verify, not read** — the contract re-review ran its own throwaway runtime scripts and caught "fixes" that were narrative.
3. **Tripwire the failure you just caught**: proxy contract test, nested-shell DOM-gone test, subsystem-presence text test. Agents repeat failure modes; tests don't forget.
4. **Never let a dispatch run non-exiting commands** (memory: dispatch-no-nonexiting-commands) — a runner hung 8 hours on `pnpm dev`; 0-byte output + old pushed commits = look for the hung child and kill it.
5. Traps hit: PS5.1 `Out-File -Encoding utf8` BOM breaks vercel.json (printf from bash instead); Windows curl needs `--ssl-no-revoke`; npm registry propagation lag looks like a missing package; GitHub "base branch was modified" merge error is transient (retry); a green publish workflow with NOT-FOUND packages means check the log for per-package outcomes before theorizing.
