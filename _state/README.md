# Per-seat living state

Seats write `_state/<namespace>/STATE.md`. Shared standing decisions: `_state/shared/STANDING_DECISIONS.md`. Combined pickup `_STATE.md` is generated by `node scripts/state/generate-combined.mjs`. A drift check is `node scripts/state/check-generated.mjs`.

Do not edit `_STATE.md` by hand.

Scope rule (2026-09-11, P-168): `_state/shared/STANDING_DECISIONS.md` carries fleet-wide rulings only. Program law, meaning any ruling that needs a plan row id to be stated, lives in `_catalog/program_preambles/<PROGRAM>.md` and reaches lanes through `scripts/dispatch.mjs` by row membership (`_catalog/plan_registry.json` `programs`). `generate-combined.mjs` refuses to regenerate while a shared bullet names a plan row; the check and its self-test are `scripts/enforcement/standing-decisions-scope.mjs`.
