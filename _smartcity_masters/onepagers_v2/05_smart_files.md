# Search Everything Your City Holds, From One Place

A document lives once and shows up everywhere it belongs. Revise it once and it is current everywhere at once, and the previous version is still there when you need it. Your data is yours.

Four systems and a shared drive. Five copies of the same document, and nobody sure which one is current. The version somebody updated last year that never made it into the packet. Every person in a city hall has lived this. Smart Files is that problem, gone.

## What it does

**Find anything, from one place.** One search across everything your city holds, instead of four systems and a shared drive.

**One document, everywhere it belongs.** A document lives once and shows up everywhere it belongs. Not five copies in five folders; one record, with every place that needs it pointing at the same thing.

**Revise once, current everywhere.** A change lands everywhere that document appears. Nothing is silently lost; what it was before is still there.

**You decide who sees what.** Some of what your city holds is public. Some is for one department. Some is for a named few. That control is built into the record itself.

## An assistant that can actually answer

An assistant follows you through the system and can actually answer, because everything underneath it was built to be read.

## The same foundation everything else reads from

Dashboards, Plan Review, and Asset Management all draw from the same record Smart Files searches. A plan set cited in a review, an as-built attached to an asset, an ordinance a dashboard references: one search finds them all, and revising any of them once makes it current everywhere it is referenced.

## Why everything else works.

The way we capture and process data is the foundation for everything else to get built. Smart Files is the part of that foundation you touch every day.
